# 当前页面设计方向

用户要求：收集至少20个游戏或B/S平台的布局参考，字体和页面风格应具有简洁游戏的清爽感；IEEE CoG 2027是明确认可的参考方向。

本次已整理[22个实测页面、20个GitHub项目及复现分析](https://baichunhui-9803.github.io/hex-research-platform/docs/design-reference-library-20261115/index.html)，并独立制作三种可运行原型。字体建议为Inter主体、JetBrains Mono数据与短标签、可选Noto Serif JP展示标题。

设计建议：CoG式首页负责平台气质，画布优先的工作台负责操作，问题与方法的并列关系借鉴Elevator Saga；详细算法说明放在方法页，工作台保持必要控制与反馈。

当前状态：用户已授权按推荐实施。0.2版正式平台采用CoG式深色入口、浅色画面优先工作区、Inter正文与JetBrains Mono数据；展示标题使用Noto Serif JP。原型作为研究记录保留，仿真规则保持独立。

后续实施以[设计令牌建议](design-reference-library-20261115/design-system.json)、[中文分析](https://baichunhui-9803.github.io/hex-research-platform/docs/design-reference-library-20261115/report.zh-CN.html)和[可运行原型](https://baichunhui-9803.github.io/hex-research-platform/docs/design-reference-library-20261115/prototypes/index.html)为依据。
