# 整合验证记录

## 0.5 版冻结目标

- 参考库 `HEX-20261120-A` 覆盖 393 个规划实例，含 361 个可建立正改善目标的实例。整局归档 71 种设置、846 局。
- 增补新种子 29、30、31，在 34 种设置下独立配置 24、48、96 次评价预算。102 个规划实例用 CMA-ES、JADE、原生多起点建立参考。留出方法为惯性 PSO、(1+1)-ES、禁忌搜索。30 个可配对设置的未达标率误差由 24.0 降到 16.3 个百分点，地铁子集未改善。
- 追加 639 局仿真，覆盖 11 个原始场景与 30 个融合配对的开关对照。270 个融合配对中，双向联动使联合目标通过率提高 21.1 个百分点，平均送达率下降 4.7 个百分点。
- 37 项自动化测试核对精确匹配、目标评分、分母、原规则和 HTTP API。
